## Hasil implementasi

- **NS-BUG-001:** pergantian identitas mereset kedua Zustand editor, termasuk history, selection, model URL dan decal. Outlet editor di-mount ulang pada perubahan generasi sesi. Respons API dari sesi sebelumnya ditolak sebelum dikonsumsi. Callback image/FileReader juga memeriksa generasi atau dibersihkan ketika unmount. Shortcut GET 2D sekarang hanya berlaku sekali untuk project yang baru dibuat pada instance editor tersebut.
- **NS-BUG-002:** acknowledgment save 3D memeriksa identitas dokumen dan snapshot yang dikirim. Edit lebih baru tetap utuh dan dirty. Create hanya memperbarui URL tanpa reload snapshot lama; respons dokumen/sesi yang sudah ditinggalkan diabaikan. Inspector dan notifikasi menjelaskan bila masih ada perubahan belum tersimpan.
- **NS-BUG-003:** gambar katalog baru menyimpan path stabil `/api/catalog/editor-image/:slug`, tanpa token kedaluwarsa. Setiap request memeriksa auth/lisensi sebelum redirect no-store ke signed URL baru. Bila gambar lama gagal, resolver mengenali key storage lokal atau endpoint/bucket R2 yang dikonfigurasi, mencocokkannya dengan aset 2D dan memeriksa lisensi kembali. URL input tidak pernah di-fetch oleh server. URL arbitrer, traversal, key tidak dikenal atau lisensi yang tidak berlaku ditolak. Scene tidak dimigrasi atau ditulis ulang otomatis; transform dan history tetap memakai format existing.
- **NS-BUG-004 (ditemukan saat regresi):** perpindahan dokumen ketika Canvas R3F masih diinisialisasi dapat memanggil event connector dengan target null. Editor dan viewer memakai connector yang memeriksa target sebelum memasang listener. Tidak ada library renderer atau dependency baru.

Loading dan error gambar ditampilkan di workspace. Retry mencoba pemuatan kembali. Export 2D ditolak selama ada gambar belum siap/gagal, sehingga hasil parsial tidak dilaporkan sebagai export berhasil.

## Verifikasi DB yang masih perlu dijalankan

Saat Docker Desktop aktif, jalankan runner terisolasi existing: siapkan `tests/compose.test.yml`, migrasikan hanya database `nesomn_revision_test` melalui konfigurasi sintetis `releaseEnvironment('integration', {...process.env, NESOMN_DISPOSABLE_TESTS:'1'})`, lalu `node scripts/test-phase9.mjs integration`. Tes baru memeriksa anonymous 401, pengguna tanpa lisensi 403/404, pemilik 302 dengan no-store, pemulihan URL lama, URL host arbitrer, serta pencabutan lisensi. Jangan menjalankannya dengan DATABASE_URL production. Runbook detail environment/migrasi ada di [testing](../testing.md) dan [migrasi](../migrations.md).

Setelah pengujian Docker, hapus hanya container dan image yang dibuat tes tersebut, dengan pemeriksaan kepemilikan dan pemakaian image; jangan prune global atau menghapus volume/data lain. Pada pekerjaan ini daemon tidak tersedia, sehingga **tidak ada container atau image baru yang dibuat** dan tidak ada resource Docker yang dihapus.
